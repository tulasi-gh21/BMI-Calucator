A simple Python program that calculates BMI (Body Mass Index) from user input and saves the result with today's date to a history file.

## Features
- Takes weight (kg) and height (m) as input
- Calculates BMI and classifies it into a category (Underweight, Normal, Overweight, Obese)
- Saves each result with date to bmi_history.txt
